# AI拼豆图纸生成器-基于Craftsman-Agent工匠智能体的Skills和API生成

### Features 核心功能
1. 接受用户输入的prompt和参考图，转化为2维的拼豆组装图Blueprint
2. 通过Prompt可以调整拼豆结果：例如卡通化，去除背景，把背景变为白色，人物照片换风格等等。


本技能由工匠智能体Craftsman-Agent(https://craftsman-agent.aiagenta2z.com/) 提供，并且在OneKey Agent Gateway上部署路由版本，对应已注册AI Agent的ID为 `craftsman-agent/craftsman-agent` 及API ID `generate_perler_bead_pindou`，基于其注册API元数据中的 `api_list`。支持通过CLI、Skills、REST API及其他智能体Agent中使用。

## Quickstart 快速开始
设置工匠智能体(Craftsman Agent)的拼豆生成API的Access Key `DEEPNLP_ONEKEY_ROUTER_ACCESS`，这个也是 AI Agent Marketplace 智能体应用市场的 OneKey Gateway 的Access Key，
Access Key的注册地址：https://deepnlp.org/workspace/keys ，注册之后免费领取足够多次尝试拼豆转化的Credits。

设置Access Key
```bash
export DEEPNLP_ONEKEY_ROUTER_ACCESS=YOUR_REGISTRY_KEY
```

运行脚本执行  API 
- Node (JS): `node scripts/generate_perler_bead_pindou.js --data '{"key":"value"}'`
- Python: `python3 scripts/generate_perler_bead_pindou.py --data '{"key":"value"}'`

## APIs
### `generate_perler_bead_pindou`
功能：根据用户输入的Prompt 和参考图片，转化为2D的像素画拼豆图纸

- Method: `POST`
- Endpoint: `https://agent.deepnlp.org/agent_router`

#### API请求输入参数和格式

| 参数名  | 描述                                                  |
|---------|-----------------------------------------------------|
| prompt  | 描述需生成拼豆图案或者描述的文本提示词，例如：人像背景去除、背景灰色转为白色背景，卡通画风格      |
| images  | 待处理图片的URL列表                                         |
| width   | 成品板宽度，例如16表示16×16板的宽度                               |
| height  | 成品板高度，例如16表示16×16板的高度                               |
| brand   | 可选值：default, mard, artkal, perler, hama，默认的是MARD的色号 |


```example
{
  "unique_id": "craftsman-agent/craftsman-agent",
  "api_id": "generate_perler_bead_pindou",
  "data": {
    "prompt":"",
    "images":[
      "https://minecraft.wiki/images/Diamond_Pickaxe_JE3_BE3.png?7409d="
    ],
    "width":16,
    "height":16,
    "brand": "default"
  }
}
```

```bash
  }
}'
```
